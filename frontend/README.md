# CloudGallery

CloudGallery is a web application that allows users to upload, view, and manage both images and videos. This project is built using Node.js and Express for the backend, with a React-based frontend optimized for desktop use.

## Features

- **Upload Images and Videos**: Users can upload both image and video files to the gallery.
- **Image and Video Display**: Uploaded media is displayed in a card format with an overlay menu for quick actions.
- **Three-Dot Menu Options**:
  - **Delete Media**: Allows users to delete specific images or videos.
  - **Zoom Image**: Provides a pop-up view to zoom into an image.
- **Wave Overlay Animation**: A smooth animation overlay for media cards.

## Prerequisites

- **Node.js** and **npm** installed on your machine.
- **MongoDB** for storing metadata of uploaded files.
