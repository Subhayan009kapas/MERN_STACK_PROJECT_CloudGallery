# **CloudGallery** 📸🎥

CloudGallery is a full-stack web application that allows users to upload, view, and manage images and videos seamlessly. Built with the **MERN stack**, it provides a smooth and efficient media handling experience.

---

## 🚀 **Features**

✅ **User Authentication** (JWT-based login and registration)\
✅ **Secure File Uploads** (Multer for handling image/video uploads)\
✅ **Media Management** (View, delete, and zoom-in features)\
✅ **Interactive UI** (React-based dynamic interface)\
✅ **Fast & Scalable Backend** (Node.js & Express.js for server-side processing)\
✅ **MongoDB Database** (Efficient storage and retrieval of media files)

---

## 🛠️ **Tech Stack**

- **Frontend:** React.js, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Token)
- **File Handling:** Multer (for image/video upload & storage)

## 📌 **Installation & Setup**

### 1️⃣ **Clone the Repository**

```bash
  git clone https://github.com/yourusername/CloudGallery.git
  cd CloudGallery
```

### 2️⃣ **Backend Setup**

```bash
  cd backend
  npm install  # Install dependencies
  npm start    # Start the backend server
```

### 3️⃣ **Frontend Setup**

```bash
  cd frontend
  npm install  # Install dependencies
  npm start    # Start the frontend React app
```

## 🔗 **API Endpoints**

| Method | Endpoint             | Description               |
| ------ | -------------------- | ------------------------- |
| POST   | `/register`          | Register a new user       |
| POST   | `/login`             | Authenticate user         |
| POST   | `/upload`            | Upload an image or video  |
| GET    | `/images?userId=xyz` | Fetch user-specific media |
| DELETE | `/images/:id`        | Delete an image by ID     |
